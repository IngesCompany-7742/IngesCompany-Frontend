# User Stories

This document tracks the main user stories for the DoofPlus application.

## 1. Identity & Access Management (IAM)
- **US01:** As a QA Specialist, I want to sign in with my corporate email and password so that I can access the QA environment safely.
- **US02:** As a user, I want to confirm my identity with a two-factor code so that my account remains secure.

## 2. Manufacturing
- **US03:** As a Production Supervisor, I want to view my production orders so that I can manage daily operations.
- **US04:** As a Production Supervisor, I want to monitor IoT data so that I can prevent deviations during production.

## 3. Quality
- **US05:** As a QA Specialist, I want to review batch readiness checks and apply my electronic signature to release the batch.
